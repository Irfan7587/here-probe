This project, developed during the HERE Technologies Hackathon by The Circle Finders team, focuses on filtering and labeling geospatial data based on distance metrics. 
Using both Euclidean and Great Circle distances, we applied a threshold approach using the 75th percentile for one group and the 25th percentile for another to isolate key data points. 
The filtered dataset is then categorized into two labels: one for points within a specific area of interest (e.g., near roundabouts) and another for points outside that area.
The analysis includes both training and testing datasets, detailing the distribution of labels. 
This README provides an overview of our approach and serves as the foundation for further exploration and refinement.
